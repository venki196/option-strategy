Option chain, strategies by market view, Nifty futures with hedge, live ticks and order ticket.

Connect

Consumer key, UCC and mobile are kept on this device. TOTP and MPIN are never stored.

App lock

The PIN hides the screen. It is not encryption, and fingerprint unlock needs a native plugin that this build does not include.

Alerts

Alerts appear as a banner with a beep and vibration while the app is open. System notifications work only if the notification plugin is in your build.

Position sizing

Live order safety

These checks run before any live order. The kill switch and loss limit never block a square-off.

Option chain recording

While the app is open in market hours, the chain you are viewing (strikes, prices and OI) is saved on this phone, so the option signals can be tested on real data later.

Signal settings

Signals use only a fast and a slow moving average and RSI, on monthly, weekly, daily, 1 hour, 15 min and 5 min candles. A timeframe is bullish when fast is above slow and RSI is above 50, bearish for the reverse, and neutral otherwise.

Stored history (on this phone)

Daily candles (about 6 years) and hourly candles (about 3 years) for each index are saved in the phone's database. Each sync fetches only the missing days, and weekly candles are built from the daily ones. The first sync of an index takes a few minutes because of Kotak's rate limit.

Scans the nearest expiry of each index with a smaller strike window. The first scan makes many calls and can take a couple of minutes.

Tests the Swing rule (fast/slow average and RSI) (weekly and daily trend agree, RSI filters) on the selected index over about 3 years of daily candles.
